# Security policy

Please do not report security vulnerabilities in public issues, discussions or
pull requests.

Report them privately through GitHub's private vulnerability reporting: open
the affected repository, go to the **Security** tab and choose **Report a
vulnerability**. For the main project, use
[WasmKeep/wasmkeep](https://github.com/WasmKeep/wasmkeep/security/advisories/new).

WasmKeep is pre-alpha software and has no supported release yet; reports are
handled against the latest code on the default branch.
